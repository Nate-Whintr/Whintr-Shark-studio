About Whintr Studios, a Solo Indie Game Developer

Whintr Studios is a one-person game studio run by Nate Whintr. Making my own games has been my goal for as long as I can remember, and this studio is how I do it.

How I work as a solo game developer

  • One developer handles design, code and release
  • Games are sold once and yours to keep
  • Progress is shared openly on the project news page

Tools and communities

I follow the W3C accessibility guidance on this site, and I share games on itch.io. My code is on GitHub.
